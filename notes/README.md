# Working notes

Frozen records of how the framework got to where it is: original briefs, plans as
they were written, and roadmaps as they stood on a given day.

**Nothing in this directory is current documentation.** Every file is named for the
date it was last true and carries a banner saying so. They are kept because the
reasoning in them is worth having; they are not maintained, and their checklists,
version numbers and paths are stale by design.

For the framework as it is today:

- Product direction — [../VISION.md](../VISION.md)
